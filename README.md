# Nature Invest

Cria uma plataforma para investimento que logo que a pessoa clicar no link ser direcionado para a parte de cadastro usando o nome completo , número(na parte de número deve aparecer uma opção para ele escolher a região dele e independente da sua região para combinar com o número do certo pais,senha e repetir senha.(na parte de senha coloca um olho para ver a senha).

E outra parte para login usando número e senha.

Depôs do cadastro ou login deve ser direcionado para a página inicial onde há propagandas em formato de áudio de duração de 5 minutos mostrando imagens sobre a natureza (plantas,animais, águas é muito mais)

Na parte de baixo coloca 5 ícones(início, convide,carteira, transações,fundo, perfil,roleta da sorte check in diário de 5mzn á 1mzn aleatório.)

B1. O valor do produto 600mzn duração 365 dias.

B2. O preço do produto 1500mzn duração 365 dias.

B3. O preço do produto 5000mzn duração 365 dias.

B4. O preço do produto 15000mzn duração 365 dias.

B5 .o preço do produto 45000mzn duração 365 dias.

B6.o preço do produto 75000mzn duração 365 dias.

B7.o preço do produto 120000mzn duração 365 dias.

B8 .o preço o produto 25000mzn duração 365 dias.
